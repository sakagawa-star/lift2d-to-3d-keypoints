## 1. 目的と経緯

- feat-027 / feat-029 の手動テスト合格条件として「旧 Blender パイプラインで作った映像との比較」が必要（2026-08-10 ユーザー決定）

## 2. データフロー（両経路の共通出発点 = 平滑化済みNPZ）

```
phase4/data/session001_f145749_world300.npz（生・300フレーム・NaNゼロ〔仕様書確認済み〕）
  └─ filter_npz.py --fps 30 → 平滑化済みNPZ
       ├─ 新経路: render_fps_video.py --dump-poses → new_poses.json
       └─ 旧経路: npz_to_c3d.py --fps 30 → C3D
```

## 4. リグ再構築の方針（ラッパースクリプトで行うこと）

1. 空シーンで平滑化済み C3D を `bpy.ops.import_anim.c3d` でインポート。新アーマチュアは名前を決め打ちせず**インポート前後のオブジェクト差分で特定**する
2. 既存 .blend（`phase4/data/Blender/session001_world_22pt.blend`）から `Cam_Anchor` / `Cam_FPS` を append（親子関係は保持される）
3. `Cam_Anchor` の ARMATURE 制約ターゲットを**決定的に再構築**する（既存ターゲットをクリアし、新アーマチュアの LEye / REye を weight 1.0 ずつで追加。append で切れた参照の穴埋め推測はしない）
4. シーンのフレーム範囲を 1〜300 に設定し、`fps_camera_pose.export_camera_poses()` を呼ぶ
5. 安全網: 同関数内蔵の検証（カメラの親=アンカー・ローカル回転ゼロ・必要ボーン存在・**毎フレームのカメラ位置=両目中点/向き整合**）が、リグ組み立てミスを exit 1 で検出する
