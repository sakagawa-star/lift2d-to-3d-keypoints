# feat-026: レンダリング＋自動マッチングによる外部パラメータ自動リファイン

## ステータス

構想段階（Open）。`pipeline.md` を Codex レビュー予定。requirements.md / design.md は未作成（レビューと検証実験 A〜C の結果を踏まえて作成する）。

## 概要

K・歪み既知の実カメラの外部パラメータ推定において、現行の手動プロット（1 カメラ 20 点超の 2D/3D 対応付け）を初期値用の 5〜6 点に削減し、最終精度は「3DGS レンダリング（色＋深度）→ 実写との自動マッチング → 深度による 3D 化 → PnP → 反復」の全自動リファインで確保する。

- 課題: 手動プロットの作業量と人的ミスによる精度劣化
- 先行研究: GS-CPR (ICLR 2025, arXiv:2408.11085) と同構図
- 詳細: `pipeline.md`（パイプライン定義・全変数・成立性解析・検証実験計画）
