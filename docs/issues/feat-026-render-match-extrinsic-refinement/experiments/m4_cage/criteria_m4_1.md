## 1. 実験の問い

M4 No-Go の失敗要因②「M2（病院シーン・連続面支配）で較正された深度系ゲート定数が、檻（近接 0.5〜2.5m・細線構造支配）では変位ゲート通過分の 60〜75% を除外する」に対し、**深度ゲート定数の再較正のみで成立性（ゲート後 N ≥ 30）が回復するか**を判定する。

**スコープ限定（明示）**:

- 失敗要因①（ratio 律速のマッチ枯渇。ratio 後 97〜109 件）には**一切手を付けない**。SIFT・ratio 0.75 は固定。したがって本実験が Go でも、マッチ母数の薄さに起因する頑健性の議論は残る（対処はマッチャー変更＝候補3。別実験）
- 変更対象はゲートの**定数のみ**。ゲートのアルゴリズム変更（例: 2×2 近傍の NaN 画素を除いた有効画素のみでの補間、重み付き PnP 化）はスコープ外
- 判定範囲は M4 と同じ「パイロット範囲（cam05520125）での成立判定」

## 2. 入力データ（M4 と同一。固定)

M4 criteria §2 の入力（PLY・intrinsics_all.toml・実写クエリ cam05520125.png・手動6点・レンダ設定・座標系確認）をそのまま使う。差分なし。

M3 回帰チェック（§7）のみ M3 の入力（`../m3_realquery/` の cam05520126 のデータ・20点方式初期値+摂動）を使う。

## 3. 変更対象の定数と較正グリッド（事前固定・事後追加禁止）

### 3.1 振る定数（2つ）

| 定数 | 現行値（M2較正） | グリッド | M4 実測の除外実績（チェーンA、変位後78件中） |
|---|---|---|---|
| `rel_spread_th`（bilinear 2×2 近傍の深度広がり / 中心深度） | 0.05 | **{0.05, 0.10, 0.15, 0.20}** | NaN/広がり除外 31件（40%）と合算計上 |
| `GATE_VAR_REL`（局所分散閾値 τ_d = 係数 × 有効深度中央値、窓5px） | 0.02 | **{0.02, 0.04, 0.08}** | 分散除外 21件（27%） |

グリッドは 4×3 = 12 組。**実行後の値の追加・変更は禁止**（追加が必要と判明した場合は No-Go として終了し、次の実験を別途 criteria lock する）。

### 3.2 固定する定数（全て M4 と同一）

- `GATE_ALPHA = 0.5`・`GATE_Z_RANGE = (0.5, 10.0) m`: **M4 実測で除外 0 件**（3チェーンとも excl_alpha = excl_z = 0）のため、再較正の対象外とする根拠がデータで確認済み
- SIFT ratio 0.75、ゲート・RANSAC スケジュール（k=0: τ_px=250px/RANSAC 8px、k≥1: τ_px=10px/RANSAC 2px）、N_min=30、分散窓5px、停止判定（サンプリング型）、その他 M4 criteria §4 の全定数

### 3.3 除外内訳の分離記録（必須）

M4 の「NaN/広がり除外」は「2×2 近傍に真の NaN がある（**閾値を緩めても救えない**）」と「広がりが閾値超過（緩めれば救える）」の合算で、内訳が未記録だった。本実験では全フェーズで両者を**分離して記録**する。逐次分類の順序は depth_ok（NaN→広がりの順で判定）→ α → z → 分散とする（codex-48 の指摘事項: 分散マップは pixel_valid に依存するため、この順でないと内訳が歪む）。

## 4. 実験構成（4フェーズ。順序固定・前フェーズ不成立なら打ち切り）

### フェーズ0: 再現検証（較正基盤の疎通）

1. M4 と同一手順で 3チェーン（A 無摂動 / B・C 5cm2° 摂動 seed 11, 12）の k=0 を再実行し、**中間生成物を保存**する: ratio 後マッチ座標、変位ゲート通過対応、レンダ深度マップ・αマップ
2. 保存した中間生成物に現行定数 (0.05, 0.02) でゲートを再適用し、**下表（`m4_history.npz` の k=0 診断レコードから抽出した M4 実測値。比較の正はこの表）と完全一致することを確認**する

| チェーン | n_raw | ratio後 | n_disp | excl_depth_nan | excl_alpha | excl_z | excl_var | N |
|---|---|---|---|---|---|---|---|---|
| A | 3898 | 97 | 78 | 31 | 0 | 0 | 21 | 26 |
| B | 4461 | 109 | 66 | 36 | 0 | 0 | 16 | 14 |
| C | 4326 | 108 | 73 | 39 | 0 | 0 | 15 | 19 |

- 成立条件: 3チェーンとも上表の全列が完全一致（決定論的パイプラインなので一致するはず。不一致=実装バグであり、修正まで先に進まない）
- 注記: 現行実装の `excl_depth_nan` は「真の NaN」と「広がり超過」の合算列。フェーズ0 ではこの合算値で一致を確認し、以降のフェーズで §3.3 の分離記録を行う（分離した2列の和が本表の `excl_depth_nan` と一致することも確認する）

### フェーズ1: 較正スイープ（オフライン）

保存済み中間生成物に対し、12 組の定数で深度ゲートのみ再適用し、各組・各チェーンの N と除外内訳（§3.3 の分離込み）を全記録する。レンダ・マッチングは再実行しない（k=0 の中間生成物は定数に依存しないため）。

**定数の選定規則（事前固定）**:

1. 適格条件: 3チェーンすべてで N ≥ 30
2. 適格な組が複数ある場合: **変更度 = (rel_spread_th のグリッド番号 0〜3) + (GATE_VAR_REL のグリッド番号 0〜2) が最小**の組を選ぶ（現行値からの最小変更を優先）
3. 変更度同点の場合: **rel_spread_th が小さい側**を優先する（広がりゲートはシルエット境界の深度混合＝リフト破壊の直接の防波堤であり、緩和リスクが分散ゲートより高いため、締めたままにできるならそちらを取る）
- 成立条件: 適格な組が 1 つ以上存在すること。**12 組すべてで不適格ならフェーズ1で No-Go 終了**（フェーズ2 に進まない。「救済可能な母数が足りない」= 真の NaN が支配的、の実測として記録）

### フェーズ2: 確認実験（本実験）

フェーズ1 で選定した定数 1 組のみを用い、M4 criteria §5 と完全同一の手順（6点PnP 初期値 → 3チェーン A/B/C、seed 11, 12 → 各 k=0 + N_S=20 反復 → 60 サンプル pooled → 受理判定・二峰仲裁）を実行する。選定定数は k=0 と k≥1 の全反復に適用する。

### フェーズ3: M3 回帰チェック

フェーズ2 が Go の場合のみ実施。選定した定数で M3 の代表カメラ **cam05520126**（M3 で f_c=1.000・PASS・ratio 後マッチ 477 件の良好ケース）を criteria_m3_2 と同一の判定（3チェーン 60 サンプル pooled、f_c ≥ 0.7）で再実行し、PASS が維持されるかを確認する。

- 回帰の結果は**本実験の Go/No-Go には含めない**（判定対象は檻シーンでの成立回復）。役割は運用設計の分岐材料: PASS 維持なら「共通定数」として提案可能、FAIL なら「シーン別定数（近接シーン専用の分岐）」として提案する。どちらを採るかの最終判断は M5（要求仕様・設計）で行う

## 5. 判定基準（数値固定）

### 5.1 成立性（M4 §6.1 と同一）

1. 6点PnP が解を返す
2. 3チェーンすべてで k=0 が成立（ゲート後 N ≥ 30）し、明示的失敗なく 60 サンプルを収集できる
3. silent failure がない（失敗時は失敗段が特定できる）

### 5.2 受理（M4 §6.2 と同一）

- 単峰高合意: pooled f_c ≥ 0.7（=42/60）かつ第2クラスタ占有率 < 0.2、**または**仲裁成立の二峰（第2 ≥ 0.2、第1+第2 ≥ 0.9、手動点仲裁差 ≥ 1.0px）
- いずれも満たさなければ不受理

### 5.3 品質非劣化（本実験で追加。ゲート緩和が解を壊していないことの確認）

1. **RMSE ≤ 2.0 px**。判定母集団を一意に固定する: **§5.2 で最終採用されたクラスタ（単峰時は主クラスタ、二峰仲裁時は仲裁で選ばれたクラスタ）に属する k≥1 サンプルの反復時 RMSE の中央値**が 2.0 px 以下であること。採用クラスタ外のサンプルの RMSE はこの中央値に含めない（別途記録はする）（根拠: M3 実写収束時実測 0.90〜1.24px、M3/M4 共通の警告閾値と同値。これを合否条件に昇格する）
2. **緩和救済点の追跡（記録。合否には使わない）**: 「現行定数 (0.05, 0.02) なら除外されていたが選定定数で通過した点」をフラグし、(a) RANSAC インライアに占める割合、(b) 救済点のみの再投影残差分布、を全反復で記録する（壊れた深度の混入を直接観測する手段。閾値は根拠となる事前実測がないため設けない）
3. 退化診断（λ3/λ1・深度レンジ・凸包面積比）・クラスタ RMS 半径は M4 §6.5 と同一の暫定警告閾値で記録（合否に使わない）

### 5.4 総合判定の前提条件（M4 §6.4 と同一）

- 6点PnP 初期解と最終解の差が M2 実測収束域（位置 ≤ 50cm かつ角度 ≤ 10°）の内側にあること

### 5.5 M4-1 全体の Go / No-Go

- **Go**: フェーズ2 で §5.1 + §5.2 + §5.3-1 + §5.4 をすべて満たす
- **No-Go**: フェーズ1 で適格定数なし、またはフェーズ2 で上記のいずれかを満たさない。失敗段（真の NaN 支配 / N 不足 / 多峰 / RMSE 劣化 / 収束域逸脱）を特定して記録し、候補2〜5 の検討材料とする
- 回帰チェック（フェーズ3）の結果は Go/No-Go に影響しない（§4 フェーズ3）

## 6. 試行回数の管理

- フェーズ1 のスイープは 12 組の一括評価を **1 回のみ**実施（グリッド外の探索・再試行は禁止）
- フェーズ2 は選定された **1 組のみ**で **1 回のみ**実施。フェーズ2 が失敗した場合に「次点の定数で再実行」は**しない**（それは結果を見た定数選び直しであり、なし崩しの再較正になる。必要なら別実験として criteria lock する）
- フェーズ3 は 1 カメラ・1 回のみ
