### 照合（2026-08-01）

- 成立性の予測（成立）は**外れ**。外れの内訳が檻固有の2要因を定量特定した:
  1. **ratio後マッチ数が予測 200〜600 に対し実測 97〜109**（M3 実写 258〜446 の 1/3〜1/4）。生候補は 4300 件あるのに ratio test で 97.5% が落ちる——檻の格子・金網の周期構造で記述子が曖昧化し、最近傍と第2近傍の距離比が締まらない（(b-3) が誤マッチではなく**マッチ数の枯渇**として発現）
  2. **深度系ゲートが変位通過分の 60〜75% を除外**。NaN/広がり除外（40〜55%）は細線・金網のシルエット境界で 2×2 近傍の深度が跳ぶため、分散除外（20〜27%）は格子越しの背景で局所深度分散が大きいため。M2/M3（壁・床など連続面が支配的な病院シーン）で較正されたゲートが、細線構造だらけの檻では通過点をほぼ残さない（(b-2) の答え）
- 予測が当たった項目: 深度除外は M3 より高率（方向は的中、程度は予測以上）、レンダ品質良好（b-4 は問題なし＝「3DGS 再撮影」の分岐は根拠なし）、6点PnP・初期ポーズは良好
- **失敗モード = 「マッチ不足（ratio 律速）+ 深度不良（細線構造）」の複合**。首振り型の角度誤差ではないため Stage 1.5（回転粗整列）は適用対象外（レスキュー実行せず）
- criteria の定数・閾値は動かしていない。次の一手（roadmap の切り分けフロー: マッチャー変更 / ゲート定数の近接シーン再較正を別実験 M4-1 として criteria lock / 手法棄却）は**ユーザー判断待ち**

### 実測（2026-08-02）

- **フェーズ0: 成立**。3チェーンとも期待値表と全列完全一致（スイープ基盤は M4 と同一であることを確認）
- **フェーズ1: 適格組なし → No-Go（criteria_m4_1 §5.5。フェーズ2 に進まない）**
- 全12組×3チェーンの内訳: `m4_1_sweep_table.csv`。要点:
  - **真NaN除外 = 全チェーン 0 件**（除外は 100% 広がり超過。深度NaN画素は実質存在しない）
  - **広がり緩和は分散ゲートに丸ごと吸収される**: var=0.02 固定で spread を 5→20% に緩めても N は 26/14/19 から**1件も動かない**（例: チェーンA で excl_spread 31→8 に減った分、excl_var が 21→44 に増加。救済点が全量、分散ゲートで再除外される完全な冗長関係）
  - **分散緩和のみが N を動かすが飽和する**: var 2→8%（τ_d² で16倍）でも A: 26→39 / B: 14→24 / C: 19→26。最大緩和 (0.20, 0.08) でも B=24 < 30
  - 実測救済率: A 25% / B 19% / C 13%（変位通過分の除外に対する回復率）

### 照合（2026-08-02）

| 予測 | 実測 | 判定 |
|---|---|---|
| フェーズ0 完全一致 | 完全一致 | 的中 |
| 真NaN 0〜5件/チェーン | 0件（全チェーン） | 的中（除外の実体は広がり超過側） |
| 最大緩和での N: A 40〜60 / B 25〜45 / C 30〜50 | A 39 / B 24 / C 26 | **全チェーンで下限割れ**（救済率 13〜25% は予測 30〜60% を下回る） |
| 適格組が存在する | 存在しない | **外れ** |

- 外れの原因（内訳データから確定）: 除外点は「閾値をわずかに超えた較正ミスマッチ」ではなく、**広がり・分散の両方を同時に大きく超える真の深度不連続点**（細線・格子のシルエット跨ぎ）だった。広がりと分散は同じ点集合に冗長に発火しており、片方を緩めても他方が捕まえる。つまり M4 の要因②は「病院較正の定数が細線シーンに合っていない」のではなく、**「細線シーンではマッチ点の相当数が本当に深度リフト不能な場所に乗る」**が正しい解釈
- 含意: 深度ゲートの**定数**再較正（候補1）ではこのシーンの成立性は回復しない。回復経路は (a) マッチ母数を増やして除外率を数で吸収する（候補3: マッチャー変更）、(b) ゲートのアルゴリズム変更（有効画素のみの補間、不確実性重み付け等。候補1のスコープ外と criteria §1 に明記済み）、のいずれか
- criteria_m4_1 のグリッド・選定規則は動かしていない（§6: 事後追加・次点再実行の禁止を遵守）
