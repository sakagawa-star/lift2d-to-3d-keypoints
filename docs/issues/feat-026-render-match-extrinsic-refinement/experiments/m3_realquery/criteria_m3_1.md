## 1. 検証対象の方式（サンプリング型停止判定）

- 各系列: k=0 は現行どおり（緩ゲート τ_px=250px/RANSAC 8px を1回）。その後 **k≥1 の引き締め条件（τ_px=10px/RANSAC 2px）で停止せず固定 N_s=20 回反復**し、各反復の解を全て収集する。反復・ゲート・PnP の処理自体は M3（`m3_run.py`）と同一
  - N_s=20 の根拠: (a) クラスタ平均の標準誤差 ≈ σ/√n。実測ジッタ1歩 σ ≤ 13mm・クラスタ内 n ≥ 14 のとき ≤ 3.5mm となり、同一解閾値 1cm の 1/3 以下・一致性 p95（≥18.4mm）の 1/5 以下＝判定の分解能として十分。(b) 占有率 f_c の分解能 1/20=0.05 が閾値 0.7 の判定に足りる。(c) 計算量: 16系列 × 21反復 ≈ 336 反復で、M3 本実験（約90反復）の約3.7倍＝数時間以内に収まる
- ゲート由来の失敗（N_in<30・PnP失敗）が起きた場合は従来どおり**その場で明示的失敗**（サンプリング続行しない）
- 解の座標系（6次元）: 収集した最初の解 x_1 を基準に、位置 = カメラ中心差ベクトル [m]（3次元）、回転 = x_1 に対する相対回転ベクトル [deg]（3次元）。角度は最大 0.3° 級で so(3) 接空間の線形化が成立する
- RANSAC 乱数: 反復 j ごとに `cv2.setRNGSeed(seed_series + j)` で決定的に変える（再現可能なサンプリング）
- **合意クラスタ**: 各サンプル i について「位置距離 ≤ r_pos かつ角度距離 ≤ r_ang」の仲間数を総当たりで数え、仲間集合が最大のものをクラスタとする
  - **r_pos = 2.0cm / r_ang = 0.30°**
  - 根拠: M3 実測のジッタ1歩（5〜13mm / 0.07〜0.27°）の上側を包含する半径（1歩でクラスタから抜けない）。M3 の k≥1 の全反復の更新量のうち 2cm を超えたのは 1/49 のみ（554 P2 の 22.9mm）
  - 注意: r_pos=2.0cm は cam41520554 の一致性 p95（1.84cm）を**上回る**。クラスタ半径は「同一解とみなす近傍」の定義であり正確度の保証ではないため、**正確度は §3 条件2 の p95 照合で別途担保する**（全系列の最終解を基準ポーズと p95 で照合）
- **受理条件**: クラスタ占有率 f_c = |クラスタ| / N_s **≥ 0.7**（= 20サンプル中14以上。**14/20 未満は不合意**）なら「解が合意」として受理。**最終解 = クラスタ内サンプルの平均**（クラスタ外の外れ解は構成上除外される。単純平均・成分中央値を全サンプルに適用しないのは外れ値耐性がないため）
  - 根拠（0.7）: M3 実測で「1歩が r_pos を超える飛び」の頻度は約 2%（1/49）→ 20サンプル中の期待外れ数 0.4個。f_c≥0.7 は外れ6個まで許容し、観測頻度の**15倍のマージン**を取った保守側設定。これを超えて散る状態は「ジッタ」ではなく解釈の割れ（多峰）か発散であり、受理すべきでない
- **診断値**: クラスタ内 RMS 半径（位置・角度別）、f_c、第2クラスタ占有率（≥0.2 なら「二峰」と分類）。いずれも記録し、M5 の受理条件設計の材料とする
- **不受理**: f_c < 0.7 → 「解が合意しない」として明示的失敗（黙って悪い値を返さない）

## 2. 検証実験の構成

- 対象: 5カメラ × P0/P1/P2 の15系列（M3 と同じ初期値・同じ摂動 seed）。P3/P4 は cam05520129 のみ情報系列として実施
- 実行条件: M3 と同一（PLY・Config_scene の K/歪み・実写クエリ・near_plane・ゲート定数）
- **負対照（偽受理チェック）1ケース**: cam05520129 のポーズ・レンダに対し、クエリだけ別カメラ（cam41520557）の実写に差し替えて実行。正しい対応が存在しないので、**受理されないこと**（ゲート失敗 または f_c < 0.7）を要求

## 3. 判定基準（実行前固定）

以下の5条件を**すべて**満たせば M3-1 は Go（新停止規則を M5 設計入力として採用）:

1. **救済**: M3 で不成立だった判定系列（129 P0・129 P2・554 P2）が受理される
2. **正確度（全系列必須）**: 判定15系列**すべて**の最終解が、各カメラの基準ポーズと §5.3 の p95 閾値以内で一致する（救済系列だけでなく既存成立系列にも課す。サンプリングで測れるのは精度のみなので、正確度の drift はこの照合で検出する）
3. **無退行**: M3 で成立していた12系列が全て受理され、最終解が M3 の解と r_pos/r_ang（2cm/0.3°）以内で一致する
4. **同一解**: 各カメラの P0/P1/P2 の最終解が相互に最大ペア間 1cm/0.1° 以内（criteria.md §5.2 と同値。クラスタ平均は単発解よりばらつきが小さいはずなので、同じ閾値で厳しくなる方向）
5. **単峰性・負対照**: 判定15系列のいずれにも第2クラスタ占有率 ≥ 0.2 が**現れない**こと（現れたら多峰＝F2 分岐として No-Go）。かつ、偽受理チェック（負対照）のケースが受理されないこと

- いずれか不成立 → `experiment_log.md` に事前定義した次策（F1: ロバスト重み付き推定 / F2: 多峰の原因領域マスク・M3b / F3: K・歪み見直し / F4: 複数チェーン）へ。どの失敗モードかは f_c・RMS 半径・第2クラスタ・中心の偏りの実測値で分類する
- 予測（数値）は実験直前に `experiment_log.md` に記録する（予測→実行→照合の運用を継続）

## 4. 実行手順

1. 本 criteria の Codex レビュー収束 → ユーザー承認（lock）

3. 実測を判定基準と照合し、`experiment_log.md` に記録
