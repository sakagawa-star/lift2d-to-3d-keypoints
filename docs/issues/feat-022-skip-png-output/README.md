# feat-022: render_keypoints.py --no-png オプション（MP4のみ出力）

## ステータス

Closed（2026-07-03 完了。Codexレビュー3サイクル → 実装 → pytest 7件パス → 実機手動テストOK）

## 概要

`phase4/render_keypoints.py` で `--mp4` を有効にして数万フレームを処理すると遅い。
支配的コストはフレームループ内の `cv2.imwrite` によるPNG保存（zlib圧縮がシングルスレッドで
フルHD 1枚あたり約30〜80ms。数万フレームで数十分〜1時間超）。MP4だけ欲しい場合でも
連番PNGが無条件に保存される設計のため、このコストを回避できない。

本案件では `--no-png` オプションを追加し、`--mp4` と併用したときに連番PNG保存を
スキップしてMP4のみを出力できるようにする。

## 背景

- feat-017 で全フレーム対応（連番PNG + MP4）を実装した際、PNG保存は無条件、MP4は `--mp4` でのオプトインとした
- 数万フレーム規模の処理でPNG保存がボトルネックになることが判明（2026-07-02 検討）
