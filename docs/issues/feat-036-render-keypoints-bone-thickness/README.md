# feat-036: render_keypoints.py ボーン線の太さ変更（視錐台ワイヤフレームは現状維持）

## ステータス

Closed（2026-09-16 手動テスト合格・完了処理済み）

## 概要

`phase4/render_keypoints.py` の動画モードで描くスケルトンのボーン線が細く見にくいため、ボーン線の太さを 2px から 20px に変更する。FPSカメラ視錐台ワイヤフレーム（feat-034、`--fps-frustum`）の線の太さは従来どおり 2px のまま維持する。

## 背景

- 現状、ボーン線（`draw_overlay`）と視錐台ワイヤフレーム（`draw_frustum`）は同一の定数 `LINE_THICKNESS = 2` を共有している（feat-034 の要求「線の太さは既存ボーンと同じ `LINE_THICKNESS`」による）
- そのため `LINE_THICKNESS` を書き換えるだけでは視錐台も太くなる。ボーン用と視錐台用に定数を分離する必要がある

## ヒアリングで確定した要件（2026-09-15）

- 太さの変更手段: **定数の変更のみ**（CLI オプション・設定YAMLキーは追加しない）
- ボーン線の太さ: **20px**
- キーポイント円（黄、`POINT_RADIUS = 4`）: **変更しない**
- 視錐台ワイヤフレームの太さ: **変更しない**（2px）

## 作業ツリーの状態（起票時点の事実）

- 起票時点の作業ツリーでは `phase4/render_keypoints.py` の `LINE_THICKNESS` がコミット外で `2 → 20` に書き換えられている（ユーザーの試行による変更。`git diff` で確認、2026-09-15）
- この状態では視錐台も 20px になる。本案件の実装で定数を分離し、最終状態を design.md の定義に揃える
