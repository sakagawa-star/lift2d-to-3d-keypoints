# feat-031 ヒアリング記録

- 日付: 2026-08-11
- 発端: feat-030 完了後のフルNPZ本番実行で、レンダリング結果の情報をテキストに保存したいという要望

## ユーザー指定の保存項目（原文順）

1. 動画のファイル名
2. レンダリングの所要時間
3. 描画フレーム平均
4. レンダリングした動画の総フレーム数
5. フレームレート
6. NaNで黒くしたフレーム数
7. NaNで黒くしたフレーム番号
8. 解像度

## 決定事項

| # | 論点 | 決定 |
|---|---|---|
| 1 | 保存先・ファイル名 | **`<MP4名>_info.txt`**（例: `test_fps.mp4` → `test_fps_info.txt`）。MP4 と同じディレクトリに自動生成。オプション指定不要で常に保存 |
| 2 | フレーム番号の表記 | **NPZ の frame_id 基準、連続区間で圧縮**（例: `1200-1239, 35001, 47800-47989`） |
| 3 | 縮退フレームの扱い | **別項目で記載**（NaN と縮退を別々の項目〔件数・番号〕として記載し、黒画面の全内訳がわかるようにする） |
| 4 | ファイル形式 | **`key: value` の日本語ラベルつきテキスト**（1行1項目、人間が読む前提）。承認されたプレビュー: 動画ファイル/総所要時間/描画フレーム平均/総フレーム数/フレームレート/NaN黒フレーム数/NaN黒フレーム番号/解像度 |
