# feat-038: render_keypoints.py 複数人全員のFPS視錐台の同時描画

## ステータス

Closed（2026-10-21 手動テスト合格・完了処理済み。Codex レビューは codex-01〜03 で収束）

## 概要

`phase4/render_keypoints.py` の複数人モード（feat-037）では、`--fps-frustum` の視錐台（FPSカメラの視野方向を示す四角錐ワイヤフレーム）を `--fps-person` で指定した1人だけ描く。これを、レンダリングしている全員分の視錐台を同時に描けるようにする。

## 背景

- feat-034 で1人分のFPS視錐台描画（マゼンタ8線分、オクルージョン考慮、FOVは `--fps-camera` / `--fps-toml`、奥行き `--frustum-depth`）を追加した
- feat-037 で複数人対応した際、視錐台は「`--fps-person`（既定1）で指定した1人だけ」と決めた（2026-10-18 ヒアリング）
- 現状の実装: `persons[args.fps_person - 1]` の1人分だけ頭部点を集めて視錐台頂点を事前計算している（`phase4/render_keypoints.py` 1255〜1269行付近）。頭部マーカー構成チェックも対象人物のファイルのみ（1212行付近）
- ユーザー要望（2026-10-20）: レンダリングされている複数人全員の視錐台を同時に描きたい

## ヒアリングで確定した要件

2026-10-20 ヒアリング:

| 項目 | 決定 |
|---|---|
| 指定方法 | `--fps-person` に `all` を追加する（`--fps-person 1` / `2` / `all`）。既定は従来どおり P1。従来のコマンドの出力は変えない |
| 人物の見分け方 | 全員マゼンタのまま（色分け・視錐台へのラベル追加はしない。人物は頭の位置と既存の P 番号ラベルで判断する） |
| FOV・奥行き | 全員共通（`--fps-camera` で指定した1台の FOV、`--frustum-depth` も共通） |
| 頭部マーカーが無い人物がいるとき | エラー終了（従来の対象人物1人へのチェックを全員に適用する） |
