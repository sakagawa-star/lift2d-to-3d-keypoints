# feat-024: render_keypoints.py 歪みモデル対応レンダリング（GT比較用）

## ステータス

Closed（2026-07-23完了）

## 目的

`estimate_camera_params.py` の推定結果（K + 歪み係数 + R, t）を**視覚的に検証する**ため、
推定カメラで 3DGS（PLY）を歪みモデル込みでレンダリングし、Ground Truth（実写画像・基準点）
と比較できるようにする。

- 起点となる問題: E0085-01 で基準_018/051 が実レンズの樽型歪みで写っているのに、
  ピンホールレンダリングでは画角外になり推定結果の妥当性を画像で確認できない（feat-023 参照）
- キーポイント描画は本案件のスコープ外（GT比較には 3DGS 背景のみでよい）

## 方針（現時点の合意事項）

- 新規スクリプトではなく `render_keypoints.py` にオプトインのフラグを追加する
  （feat-021/022 と同じ拡張様式。既定動作は不変）
  - `--no-keypoints`（仮称): キーポイント・ボーン描画とオクルージョン計算をスキップし
    3DGS 背景のみ出力
  - `--distort`（仮称): 歪みモデルでレンダリング（既定はピンホールのまま）
  - `--no-keypoints` 指定時は `c3d_path` を省略可にする（案b。予備調査で実現可能と確認済み）
- 歪みレンダリングの実現方式は2候補あり、**ステップ1のスパイクで決定する**:
  - 方式A: gsplat 1.5.3 ネイティブの 3DGUT（`with_ut=True, with_eval3d=True,
    radial_coeffs, tangential_coeffs`）
  - 方式B: ピンホールで描画 → `cv2.remap` による後処理歪みワープ

## 重要な前提知識（調査済み）

- feat-013 で「UT経路 = 黒い靄」と結論されピンホール統一になったが、この試行は
  (1) 靄の真因（`near_plane=0.01` の floater。feat-014/015 で判明）が未診断の時期に、
  (2) `with_eval3d=True` なし・`packed=False` で行われたもので、**交絡の疑いが濃厚**。
  「UT自体が使えない」とはまだ言えない → スパイクで白黒つける
- gsplat 1.5.3（現環境）の `rasterization()` は `radial_coeffs`（k1-k6）/
  `tangential_coeffs`（p1,p2）/ `thin_prism_coeffs` / `with_ut` / `with_eval3d` を持つ
  （実引数・docstring で確認済み）
- TOML の `distortions` は `[k1, k2, p1, p2(, k3)]`。gsplat へは放射系と接線系に
  詰め替えが必要

## スパイク結果（ステップ1d、2026-07-22）

条件: `handai-hosp2_20260418.ply` + `Config_scene.toml` の `cam41520554`、near_plane=0.5。
実装・実行は Sonnet サブエージェント、画像判定は Claude Code 本体と目視で実施。

| 条件 | 平均輝度 | 所見 |
|---|---|---|
| (a) ピンホール（現行同一） | 138.43 | 基準。鮮明 |
| (b) UT + 歪みゼロ（`with_ut=True, with_eval3d=True, packed=False`） | 138.33 | (a) と視覚上区別不能。画素差の平均絶対値 0.81/255（ほぼ一致） |
| (c) UT + 実歪み係数 | 138.30 | 靄・破綻なし。画像周辺（左壁の設備パネル・点滴スタンド・ドア枠）が歪み係数に応じて自然に変位。品質劣化なし |

**結論**:
- **UT経路そのものは無害**（(b)≈(a) で確定）。feat-013 の「UT=黒い靄」は
  `near_plane=0.01` の floater（feat-014/015 で判明した真因）との交絡だったと判断できる
- **方式A（gsplat ネイティブ 3DGUT）は実用可能**。方式Bのスパイクは不要
- エラー・JIT ビルド問題なし（ビルドキャッシュ有効。実行は1分未満）
- 注意点として gsplat 1.5.3 の制約 `packed=False`（UT時必須）を本実装の設計に反映すること
