### 観察された異常（原因は未調査。回避策は入れていない）
- i=4 で RMSE=0.000px・Δ_intr=0.000px・lsq_status=3 となり、i=3 とパラメータが完全に一致して収束した。iter*_matches.npz を確認すると、MASt3R のマッチの u_a と u_b の距離の中央値は i=1 以降 0.0px（i=0 は 3.75px。MASt3R 内部解像度 512 の格子に量子化されて整数画素に揃う）。写真とレンダが近づくと過半のマッチで u_q == u_r となり、反復が自己無撞着の不動点に落ちる。i=2→3 の Δ_intr は 0.843→1.719 と収束しきい値 0.5px を超えており、「収束」は i=4 の自明な不動点による。
- 評価のずれ（flowmag 画像）は、画像全体の一様なずれではなく、画像右上の壁面と右下に局所的に大きい（赤）。左下の機器まわりは小さい（青）。p95 が大きいのはこの局所領域による。
