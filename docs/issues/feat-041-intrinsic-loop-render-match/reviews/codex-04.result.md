## 新たな指摘

### 1. 重要度：中 — 逆歪み検査で除外した点と、リフト用配列の同期が欠けている

design.md §4.2.3 は、検査前に `u_pin` を作り、不合格点を `keep` から除いた後、そのまま `u_pin` から作った `rays` と `d[keep]` を乗算している。部分的に除外すると、両者の点数が一致しない。CPU で「中心の 300 点＋逆変換検査に不合格となる端の 1 点」を確認すると、除外後も最小点数 300 を満たすが、`rays` は 301 点、深度は 300 点となり、設計どおりの演算は配列形状エラーになる。

修正案: 検査合格マスクを `u_pin` にも適用し、対応する写真座標・深度・3D 点の順序と点数を揃える手順を明記する。部分除外後に 300 点以上残るケースもテストへ追加する。
