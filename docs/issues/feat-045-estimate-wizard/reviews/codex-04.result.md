## 指摘

1. **高** 照合に合格した基準点名（例 `基準_001,左`）で推定が失敗する。前処理は ObjectName を引用符なしで CSV に書くため、推定が読む CSV の列がずれる。修正案: 前処理で保持できる名前の条件を明記し、違反があれば確認画像の前に CSV 入力に戻す
2. **高** 推定失敗後に案内する再実行コマンドがそのままでは失敗する。推定は失敗しても out を作っており、同じ out では既存ディレクトリの検査で止まる。前処理も部分出力があると既存出力の検査で止まる。修正案: 推定は未使用の --out-dir、前処理はそのジョブに限った --overwrite 付きの手順
3. **高** バイト一致判定の比較元（feat044_out/）が git 管理外で、作り方が記録されていない。修正案: ハッシュを明記するか、同じ環境で既存 3 ツールを手動実行して比較元を作る手順を §6.3 に追加
