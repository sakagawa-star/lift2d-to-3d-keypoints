## 概要

同時撮影した8台のカメラの外部パラメータを、(1) 3DGSモデルへのアンカー対応点（feat-026 のレンダ↔実写 LoFTR 機構）と (2) カメラ間の実写同士の MASt3R クロス対応点、の再投影誤差を同時最小化するバンドル調整で一括推定・調整する。

## 背景

- feat-026 の単体精緻化は3DGSモデルへの整合が上限（cam05520126 の調査で、単体解は最適剛体解から 0.06cm/0.04° に到達済みと確認。2026-08-17）
- 最終用途（8台の2Dキーポイントの三角測量による3D化）にはカメラ間の相互整合性が直接効くため、多視点同時調整が必要
- クロスカメラ対応点のマッチャーは MASt3R を採用（当初の方式選定。2026-08-17）。閾値パラメータは実装後の測定実験（criteria 事前定義の「基準を測ることがゴールの実験」）で決める
- **初期ポーズ方針の改訂（2026-08-18）**: 当初は「手動基準点を拘束・初期値・評価の全てで使わず、残り6台をブートストラップ（クロスマッチ＋レンダ深度リフト→PnP）で初期化する」計画だったが、ほぼ対称なケージ環境で MASt3R の偽マッチにより全6台が誤った位置に収束することが実測で判明（`experiments/p0_bootstrap/experiment_log.md`）。ユーザー決定により**初期ポーズは全8台を手動プロット + `refine_extrinsics.py` で確定する経路**（要求仕様・設計内で「案A」と呼称）に変更。ブートストラップは主経路外に降格、Stage R は廃止、クロス対応点のエピポーラ整合フィルタ（FR-010）を新設。手動基準点は最適化の拘束・評価には引き続き使わない（初期ポーズ確定のみに使用）
