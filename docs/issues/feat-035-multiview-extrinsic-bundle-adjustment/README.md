# feat-035: 8台多視点同時外部パラメータ調整（MASt3Rクロスカメラ + 3DGSアンカー）

## ステータス

Open（要求仕様・機能設計 Codex レビュー中）

## 概要

同時撮影した8台のカメラの外部パラメータを、(1) 3DGSモデルへのアンカー対応点（feat-026 のレンダ↔実写 LoFTR 機構）と (2) カメラ間の実写同士の MASt3R クロス対応点、の再投影誤差を同時最小化するバンドル調整で一括推定・調整する。

## 背景

- feat-026 の単体精緻化は3DGSモデルへの整合が上限（cam05520126 の調査で、単体解は最適剛体解から 0.06cm/0.04° に到達済みと確認。2026-08-17）
- 最終用途（8台の2Dキーポイントの三角測量による3D化）にはカメラ間の相互整合性が直接効くため、多視点同時調整が必要
- 手動基準点は精度が悪く今後さらに悪化する前提（ユーザー方針）のため、拘束・初期値・評価の全てで手動基準点を使わない。手動基準点があるのは現状2台のみで、残り6台はブートストラップ（較正済みカメラとのクロスマッチ＋レンダ深度リフト→PnP）で初期化する
- 方式はユーザー決定済み: 案A（MASt3R ペアマッチング）採用。閾値パラメータは実装後の測定実験（criteria 事前定義の「基準を測ることがゴールの実験」）で決める
