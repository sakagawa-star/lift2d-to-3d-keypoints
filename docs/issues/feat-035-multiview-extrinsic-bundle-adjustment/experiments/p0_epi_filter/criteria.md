# feat-035 Step 3F 実験基準: エピポーラ整合フィルタの生存率測定と連結性判定（p0_epi_filter）

作成日: 2026-08-24 / ステータス: **locked**（2026-08-24、codex-29 で高・中・低ゼロ、初回で収束）

## 位置づけ

本実験は**基準を測ることがゴールの実験**（測定）であり、生存率・生存数への合格ラインは定めない（測定値を記録し、EPI_TOL_PX の最終採用値は Step 7 / FR-008 の p1_param_sweep で決定する）。ただしロードマップ Step 3F に事前定義された **Go/No-Go 判定**（下記 §4。連結性の構造判定）を含む。EPI_TOL_PX=3.0 は暫定値であり、本実験では変更しない。

実験の実行は **Stage F 実装完了後**（`filter_cross_matches` + Stage B 主経路除去 + `--init-cameras` 全カメラ必須チェックの実装、pytest 全件通過後）に行う。

## 1. 答える問い（事前定義）

- Q1: 28ペア（p0_pair_connectivity でキャッシュ済みの MASt3R マッチ NPZ）それぞれについて、エピポーラ整合フィルタ（EPI_TOL_PX=3.0、Sampson 距離の画素換算。design §2.45）のフィルタ前対応点数・生存数・生存率 [%] はいくつか（全ペアの一覧）
- Q2: 生存数 ≥ N_PAIR_MIN=50 で採用となったペア集合のグラフは、全ポーズ確定カメラ（8台）を1つの連結成分に含むか
- Q3: 生存率が著しく低いペア（生存率 20% 未満。対称偽マッチが支配的と疑われるペア）はどれか、その分布はカメラ対の幾何（対面/近接）と対応するか（記録項目。合否判定には使わない）

## 2. 実験手順

1. 入力: `phase0/data/inuyama/intrinsics_all.toml`（K・D のみ使用）、`phase0/data/inuyama/cage_refined_all8.toml`（8台の確定ポーズ。Step 3M でユーザー承認済み）、`experiments/p0_pair_connectivity/tmp/pair_*.npz`（28ペア。**マッチの再実行はしない**）
2. `filter_cross_matches`（実装後の本体関数）を上記入力で呼ぶ実験用ドライバスクリプトで実行し、ペアごとの（フィルタ前対応数、生存数、生存率、採用再判定）を記録する
3. フィルタ後採用ペアでグラフを構築し、8台の連結性を判定する（Q2）
4. 結果（Q1〜Q3）を `experiment_log.md` に記録する

## 3. 直前予測（実行直前に experiment_log.md へ記録する項目の枠）

- P1: フィルタ後の採用ペア数（28 中いくつか。生存数 ≥ 50 のペア数）
- P2: Q2（8台連結）の Yes/No 予測
- P3: 生存率の範囲（最小〜最大）と中央値の予測 [%]
- P4: 生存率最低となるペアの見込み（どの2台か）
- P5: Go/No-Go の予測

予測の根拠には p0_pair_connectivity 実測（28ペア N=124〜1943、最小ペア cam05520128×cam41520554）と p0_bootstrap の知見（対称構造の偽マッチが存在する）を用いてよい。

## 4. Go/No-Go 判定（ロードマップ Step 3F の再掲。事前定義済み）

- **Go**: Q2 が Yes（フィルタ後の採用ペアグラフで全ポーズ確定カメラ8台が単一連結成分に入る）→ Step 4（アンカー対応点取得）以降の実装・実行に進む
- **No-Go**: Q2 が No（全ペア不採用を含む）。この場合 BA 実装以降には進まず、ロードマップ記載の3選択肢をユーザーと協議する: (a) 連結成分内のカメラのみで対象縮小、(b) EPI_TOL_PX の再検討（本 criteria の改訂・再 lock を経て再実行）、(c) 方針の差し戻し
- Go/No-Go の判定結果はユーザーの承認を得てから次ステップに進む

## 5. 記録

- 実測・予測との照合・判定は `experiment_log.md` に記録する
- 乖離（予測と実測の食い違い）があった場合は原因を特定してから次フェーズに進む（CLAUDE.md 実験プロトコル準拠）

## 対象外

- EPI_TOL_PX の採用値決定（Step 7 / FR-008 の p1_param_sweep で走査・決定。本実験は暫定値 3.0 固定の測定）
- ホールドアウト残差・BA 品質の評価（Step 5〜6 で行う）
- マッチの再実行・マッチ数自体の再測定（p0_pair_connectivity の成果物を再利用する）
