### 乖離（P3）の原因分析

- ブートストラップは「反復なしの単発 PnP（RANSAC 閾値 8px）」であり、対応点は広基線の MASt3R マッチ + 較正済みカメラ側のレンダ深度リフトで作られる。深度リフトには 3DGS モデルの局所形状誤差が乗り、広基線では視線方向誤差が位置誤差に大きく変換される。この結果、ポーズ誤差は数 cm オーダーとなり、画面上では 15〜43px のずれになる
- inlier RMSE ≈5px と全画面ずれ 15〜43px の不一致は、inlier が空間的に偏在し、ポーズが inlier 領域に過適合していることを示す
- **予測の誤りの本質**: P3 と目視判定項目を feat-026 の「反復精緻化後」の品質（1px 水準）を基準に設定したが、Step 3 の成果物は「初期化用の粗いポーズ」であり、要求される品質水準が異なる。feat-026 は 5cm/2° の初期摂動から収束しており（m4 実測）、今回の数 cm 誤差は下流（Stage A の LoFTR マッチング〔k=0 は 250px 相当の許容〕と BA）の収束域に十分入っている
