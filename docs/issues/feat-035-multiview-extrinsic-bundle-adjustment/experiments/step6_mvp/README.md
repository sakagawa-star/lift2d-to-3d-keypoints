## 追加測定: BA前後のホールドアウト残差比較（2026-08-25。ユーザー依頼）

問い: BA（クロス項）は feat-026 の独立精緻化に対して実質的な改善をもたらしたか。同一のホールドアウトマッチ集合（同一シード分割）を、BA前ポーズ（cage_refined_all8.toml）と BA後ポーズ（multiview_all8.toml）でそれぞれ三角測量・再投影し、残差を比較する。本測定は判定基準を伴わない確定測定（どちらの結果でも Go/No-Go はなく、解釈を記録する）。

### 直前予測（実行前に記録）

- BA後 = 0.895px（実測済み）に対し、BA前の中央値は **1.0〜1.3px** と予測（根拠: BAコストは18%低下したがポーズ変化は 0.15cm/0.06° 以下と微小。クロス残差の改善はあるが小幅のはず）
- 差が 0.1px 未満なら「BA の実質寄与は検証のみ」、0.3px 以上なら「クロス項が有意に仕事をした」と解釈する（この解釈枠も実行前に記録）

### 実測（2026-08-25）

同一ホールドアウト集合（581点×両カメラ=1162残差、シード5000）:

| ポーズ | 中央値 | RMSE |
|---|---|---|
| BA前（feat-026 ポーズ = cage_refined_all8.toml） | 0.9197px | 1.1494px |
| BA後（multiview_all8.toml） | 0.8948px | 1.1490px |
| 差 | **-0.0249px** | -0.0004px |

### 照合と解釈

- 予測（BA前 1.0〜1.3px）に対し実測 0.92px で、予測範囲を下回った（feat-026 ポーズのカメラ間整合は予測よりさらに良かった）。BAコスト18%減の大半はアンカー項側の再配分であり、クロス整合の改善は中央値 0.025px にとどまった
- 事前定義した解釈枠（差 0.1px 未満）に該当: **今回のデータでは BA の実質的寄与は「多視点整合の独立検証」のみ**であり、ポーズの実質的改善はなかった。feat-026 の8台独立精緻化が、多視点的にも約0.9pxで既に整合していたことが確定した
- 補足: これは「BA が feat-026 と同じ処理」という意味ではない（クロス項は実写↔実写のカメラ間拘束であり情報源が異なる）。「異なる情報源で検査しても直すところがなかった」が正確な結論
