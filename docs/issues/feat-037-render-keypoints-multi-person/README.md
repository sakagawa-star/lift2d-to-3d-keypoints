# feat-037: render_keypoints.py 複数人の3Dキーポイント重ね描き

## ステータス

Closed（2026-10-18 手動テスト合格・完了処理済み。手動テストで発見した描画崩れは bug-005 として分離・先行修正）

## 概要

`phase4/render_keypoints.py` の動画モードは、キーポイント入力を1ファイル（1人分）しか受け付けない。1人につき1個の C3D ファイルを複数渡せるようにし、同じ3DGS背景の上に複数人のスケルトンを重ねて描けるようにする。

## 背景

- 現状は位置引数 `keypoints_path` が1個（`nargs="?"`）。`extract_keypoints` は既知28マーカーをラベルの完全一致で1人分だけ取り出す
- 1個の C3D に複数人分のデータを入れる運用はしない（ユーザー指定 2026-10-18）。1人 = 1 C3D ファイル

## ヒアリングで確定した要件（2026-10-18）

| 項目 | 決定 |
|---|---|
| 入力 | 1人 = 1 C3D ファイル。1個の C3D に複数人分のデータは無い |
| 指定方法 | 位置引数 `keypoints_path` を複数個に拡張する（`ply toml a.c3d b.c3d ...`）。1ファイル時は従来のコマンドがそのまま動く |
| 複数人対応の入力形式 | **C3D のみ**。NPZ は従来どおり1人（1ファイル）のときだけ使える |
| 人物の見分け方 | 配色は従来どおり（右=赤 / 左=青 / 体幹=緑 / 点=黄）。人物ラベル文字を描く |
| ラベルの文字 | 通し番号 `P1, P2, …`（指定した順） |
| ラベルの位置 | 頭部の上。3DGS に隠れていても常に表示する |
| 1人のとき | ラベルを描かない（出力は従来と同じ） |
| フレーム範囲が違うとき | 和集合。そのフレームにデータが無い人物は描かない |
| 人物同士の前後関係 | 奥の人物から描く（カメラからの平均深度で並べる。関節単位の人物間隠蔽はしない） |
| 3DGS背景との前後判定 | 従来どおり人物ごとに行う |
| FPS視錐台（`--fps-frustum`） | 指定した1人だけ描く。番号で指定し、省略時は P1 |
| point rate が違うとき | エラー終了 |
| 設定YAMLでの複数指定 | `keypoints_path` に `;` 区切りで並べる（既存YAMLに空白入りパスがあるため空白区切りは不採用。2026-10-18 調査で判明） |
