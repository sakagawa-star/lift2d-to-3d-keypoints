# feat-025: estimate_camera_params.py 推定パラメータの範囲チェック（警告出力）

## 概要

estimate_camera_params.py の推定結果（内部パラメータ・歪み係数）が物理的に妥当な範囲を外れた場合に、警告を標準出力に表示する機能を追加する。

## 背景

p1（接線歪み係数）が 0.5 以上という物理的にありえない値で推定されたにもかかわらず、基準値を知らなかったため長期間異常に気づかなかった。再投影誤差（RMSE）が小さくてもパラメータ間の相殺（過学習）で個々の値が異常になることがあり、値そのものの妥当性チェックが必要。
