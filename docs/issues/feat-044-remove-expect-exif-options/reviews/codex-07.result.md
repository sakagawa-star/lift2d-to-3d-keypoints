## 新規指摘（高）原本や設定 YAML の削除を案内してしまう

既存パスを拒否するメッセージが一律に「既存のものを使うか、手で削除してください」と案内する。原本画像や設定 YAML を出力先に誤指定した場合、表示されたパスを削除すると入力を失う。汎用エラーでは「出力先が既に存在します。別の出力パスを指定してください」と案内し、既存の写真情報ファイルを再利用する手順は利用ガイドに記載する。
